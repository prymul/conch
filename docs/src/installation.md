# Installation

**Cargo**

```sh
cargo install conch-shell
```

**Homebrew** (macOS/Linux)

```sh
brew tap prymul/conch
brew install conch
```

**Debian/Ubuntu (.deb)**

Download the `.deb` from the [latest release](https://github.com/prymul/conch/releases/latest) and:

```sh
sudo dpkg -i conch-shell_*.deb
```
